## ახალი ვერსიის შემოწმება

1. PR-ის Files changed ჩანართში შეამოწმე დამატებული `rebuild/` საქაღალდე.
2. ჩამოტვირთე branch და გაუშვი README-ის მიხედვით.
3. გაიარე TESTING.md-ის საბოლოო შემოწმებები.
4. შეგიძლია PR ჩვეულებრივი merge-ით გააერთიანო, რათა ეტაპობრივი commit-ები ისტორიაში დარჩეს. `main`-ში `rebuild/`-ის დამატება არსებულ მთავარ გვერდს არ ცვლის.
