# CV Builder 🚀

## პროექტის აღწერა

მომხმარებელზე მორგებული და ინტერაქტიული CV Builder ვებ-აპლიკაცია, რომელიც საშუალებას აძლევს მომხმარებლებს მარტივად შექმნან, დაარედაქტირონ და გადმოწერონ პროფესიონალური რეზიუმეები სხვადასხვა თანამედროვე თარგის გამოყენებით.

## გამოყენებული ტექნოლოგიები

- **HTML5 / CSS3** (Responsive Design, Flexbox/Grid)
- **JavaScript (ES6+)** (მოდულური არქიტექტურა, Web Workers)
- **Git & GitHub** (ვერსიების კონტროლი)
