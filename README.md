# CVBuilder

CVBuilder არის რეზიუმეს ონლაინ კონსტრუქტორი, რომელიც HTML, CSS და ვანილა JavaScript-ზეა აგებული და მომხმარებელს ბრაუზერში მარტივად შექმნის რეზიუმეს.

## CSS სტრუქტურა
- `css/style.css`: CSS ცვლადები (ფერები, შრიფტები, ზომები), reset და ტიპოგრაფია
- `css/layout.css`: Flexbox/Grid განლაგება (header, main, footer, ბადეები)
- `css/components.css`: ღილაკები, ბარათები, ფორმის ველები, ნავიგაცია
