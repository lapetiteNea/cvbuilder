# CV Builder Project

## პროექტის აღწერა

CV Builder არის ინტერაქტიული ვებ-აპლიკაცია, რომელიც მომხმარებლებს საშუალებას აძლევს მარტივად შექმნან, შეადგინონ და დაასორტირონ საკუთარი პროფესიული რეზიუმეები კოდში ცვლილებების შეტანის გარეშე. საიტი მოიცავს მრავალფეროვან დიზაინებსა და თემებს (Templates), რომლებიც განთავსებულია ცალკე გვერდზე.

## გამოყენებული ტექნოლოგიები

- **HTML5 & CSS3** (Responsive Layout, Flexbox, Grid)
- **JavaScript (ES6+)** (Dynamic rendering, LocalStorage, Validation)
- **Git & GitHub** (ვერსიების კონტროლი)

## ფუნქციონალი

- რეზიუმეს შექმნა და რედაქტირება რეალურ დროში.
- სხვადასხვა თემების (Templates) არჩევა ცალკე გვერდიდან.
- მონაცემთა შენახვა ბრაუზერის `localStorage`-ში.
- სრულიად Responsive დიზაინი (მორგებულია მობილურებსა და პლანშეტებზე).
