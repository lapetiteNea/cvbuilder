# CVBuilder

CVBuilder არის რეზიუმეს ონლაინ კონსტრუქტორი, რომელიც HTML, CSS და ვანილა JavaScript-ზეა აგებული და მომხმარებელს ბრაუზერში მარტივად შექმნის რეზიუმეს.

## ფუნქციონალი
- რეზიუმეს რედაქტორი რეალურ დროში პრევიუთი
- დინამიური ველები: გამოცდილების დამატება/წაშლა, უნარების ჩიპები
- ფორმების კლიენტის მხარის ვალიდაცია (სავალდებულო ველები, ელფოსტა, ტელეფონი)
- მოდალური ფანჯრები (შენახვა, წაშლის დადასტურება, შაბლონის გადახედვა)
- შაბლონების ძებნა და ფილტრაცია
- შენახვა localStorage-ში
- Responsive დიზაინი: მობილური, ტაბლეტი, დესკტოპი

## გაშვება
JavaScript მოდულები (`type="module"`) ფაილის პირდაპირ გახსნისას (`file://`) არ მუშაობს, ამიტომ გამოიყენეთ ლოკალური სერვერი:
- VS Code-ში: Live Server გაფართოება → Open with Live Server
- ან ტერმინალში: `python3 -m http.server 8000` და გახსენით `http://localhost:8000`

## CSS სტრუქტურა
- `css/style.css`: CSS ცვლადები, reset და ტიპოგრაფია
- `css/layout.css`: Flexbox/Grid განლაგება და responsive წესები
- `css/components.css`: ღილაკები, ბარათები, ფორმები, მოდალი
- `css/templates.css`: რეზიუმის შაბლონები
- `css/print.css`: ბეჭდვის სტილები

## JavaScript სტრუქტურა
- `js/main.js`: მობილური მენიუ, აკორდეონი, კონტაქტის ფორმა
- `js/validation.js`: ვალიდაცია და შეცდომის შეტყობინებები
- `js/modal.js`: მოდალური ფანჯარა
- `js/storage.js`: localStorage
- `js/templates.js`: შაბლონები და რეზიუმეს რენდერი
- `js/editor.js`: რედაქტორი
- `js/my-cvs.js`: შენახული რეზიუმეები
