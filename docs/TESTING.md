# ტესტირების ჩანაწერი

თარიღი: 2026-10-22 (Asia/Tbilisi).

## შესრულდა

- ავტომატური რვა ტესტი წარმატებულია: სავალდებულო ველები; სწორი ელფოსტა/ტელეფონი; არასწორი ფორმატი; სექციების რიგი და საზღვრები; რამდენიმე CV-ის შენახვა/განახლება/წაშლა; დაზიანებული მონაცემების დაცვა; შენახვის შეცდომა; მონაცემთა ნორმალიზაცია.
- ლოკალური HTTP სერვერი მთავარ გვერდს 200 პასუხით აბრუნებს.
- ჩაშენებულ ბრაუზერში სატესტო სახელის, პროფესიის, ელფოსტისა და ტელეფონის შევსება; განათლების დამატება; პრევიუში გამოჩენა; შენახვის წარმატებული შეტყობინება; სხვა გვერდზე გადასვლის შემდეგ შენახული ჩანაწერი სიაში ჩანს.
- შიდა HTML ბმულებისა და სკრიპტების/სტილების ფაილების არსებობის შემოწმება.

## საბოლოო მიღებამდე ხელით შესამოწმებელი

- Chrome და Firefox: ყველა გვერდი; კონსოლში შეცდომების არარსებობა.
- 375px მობილური, 768px ტაბლეტი და 1440px დესკტოპი: ჰორიზონტალური გადაცურება, მენიუ, ფორმა, პრევიუ.
- სამივე შაბლონი და ფერი; სექციების ყველა მიმართულებით გადაადგილება.
- ძიება; წაშლის გაუქმება; დადასტურება მხოლოდ სატესტო ჩანაწერზე.
- შენახულის გახსნა, შეცვლა, განახლება და გადატვირთვის შემდეგ მონაცემების აღდგენა.
- კლავიატურით მენიუ, მოდალი, Escape და ფოკუსის დაბრუნება.
- გრძელი (2+ გვერდი) CV-ის PDF: ტექსტი არ იჭრება, ფორმა არ იბეჭდება.
- Lighthouse mobile ანგარიშის შენახვა და ძირითადი შენიშვნების გასწორება.

ეს სია დარჩენილი შემოწმებებია და შესრულებულ ტესტებად არ ითვლება.

## ძირითად საქაღალდეში გადატანის შემოწმება

- მფლობელის თანხმობის შემდეგ ფაილები root-ში გადავიდა; დუბლირებული `rebuild/` და გამოუყენებელი ძველი სკრიპტები მოცილებულია.
- რვავე ტესტი root-ის `tests/` საქაღალდიდან წარმატებით გაეშვა.
- ყველა ადგილობრივი HTML ბმული და რესურსი არსებობს; root-აბსოლუტური მისამართები არ გამოიყენება, ამიტომ ბმულები GitHub Pages-ის `/cvbuilder/` ქვეგზასთან თავსებადია.
- GitHub Actions-ში დამატებულია ამ ორი შემოწმების ავტომატური გაშვება.
- ამ ეტაპზე ბრაუზერის მართვის ხელსაწყო მიუწვდომელია; წინათ დარჩენილი სრული ვიზუალური შემოწმებები შესრულებულად არ მონიშნულა.
